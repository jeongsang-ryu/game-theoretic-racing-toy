# 레이스를 어떻게 정의하느냐가 해법을 결정한다

[English](problem_formulation.md) | **한국어**

같은 1대1 레이스도 **상대를 어떻게 취급하느냐**에 따라 다른 수학 문제가 됩니다.
무시하거나, 예측하거나, 상대도 최적화한다고 보거나, 상대와 대결하며 학습하거나.

## 공통 설정

- 차량 $i \in \{1, 2\}$, 상태 $x_i = (s_i, d_i, v_i)$: 트랙 진행거리, 횡방향 위치, 속도 (Frenet 좌표)
- 입력 $u_i$ = (횡속도, 가감속)
- 동역학 $x_i^{k+1} = f(x_i^k, u_i^k)$, 트랙 경계 $|d_i| \le d_{\max}$, 코너 속도 한계 $v_i \le \sqrt{a_{\text{lat}} R_{\text{eff}}(s_i, d_i)}$
- **상호작용**: 충돌 ($|s_1 - s_2| < \ell$ 이고 $|d_1 - d_2| < w$), 슬립스트림 (바로 뒤 같은 라인이면 최고속도 증가)

상호작용이 없으면 서로 독립된 최적제어 문제 두 개입니다. 충돌과 슬립스트림이 두 문제를 하나로 묶습니다.

## 네 가지 문제 정의

### 1. 단일 에이전트 최적제어 (상대 무시)

$$\max_{u_i^{0:H}} \; s_i^H \quad \text{s.t. 동역학, 트랙 경계, 속도 한계}$$

| 입력 | 출력 | 해법 | 약점 |
|---|---|---|---|
| 내 상태, 트랙 | 내 궤적 | MPC (receding horizon) | 빈 트랙이라고 가정 → 충돌, 막힘 |

### 2. 예측 후 계획 (Predict-then-plan)

$$\max_{u_i} \; J_i(x, u_i, \hat u_j), \qquad \hat u_j = \text{예측 (예: 라인·속도 유지)}$$

| 입력 | 출력 | 해법 | 약점 |
|---|---|---|---|
| 내 상태, 상대 상태, 예측 모델 | 내 궤적 | 예측 + MPC (산업계 표준) | 상대가 **내 행동에 반응**한다는 걸 무시 |

### 3. 동적 게임 (Dynamic game)

$$\text{각 } i: \; \max_{u_i} \; J_i(x, u_i, u_j) \quad \text{s.t. 공유 동역학과 충돌 제약}$$

해 개념:

- **Nash 균형**: 모든 플레이어가 서로에게 best response. 혼자 바꿔서 이득 볼 사람이 없음
- **Stackelberg**: 리더가 팔로워의 best response $BR_j(u_i)$ 를 예상하고 먼저 결정. 앞에서 방어하는 차에 자연스러운 모델
- **Minimax (제로섬)**: 최악의 상대를 가정. 행동이 유한하면 선형계획(LP)으로 풀림 (von Neumann, LP duality)
- **Generalized Nash**: 플레이어들이 제약(충돌 회피)을 공유

| 입력 | 출력 | 해법 | 약점 |
|---|---|---|---|
| 두 차의 상태, 상대 목적함수 모델 | 균형 궤적 쌍 (내 것만 실행) | 반복 best response, KKT 쌓기 (ALGAMES), LQ 근사 (iLQGames), 유한 행동 → 행렬 게임 | 계산량, 목적함수 가정, 균형이 여러 개 |

### 4. Markov game + 강화학습 (self-play)

$$\max_\theta \; \mathbb{E}\Big[\sum_k \gamma^k r_i(x^k, a_i^k, a_j^k)\Big], \qquad a_i^k \sim \pi_\theta(\cdot \mid o_i^k)$$

| 실행 시 입력 | 출력 | 학습 | 약점 |
|---|---|---|---|
| 관측 $o_i$ (내 상태, 상대와의 상대 위치, 트랙 미리보기) | 행동 $a_i$ | PPO + self-play, 과거 스냅샷 리그 | 학습 비용, 보상 설계, 제약 보장 없음, sim-to-real |

## 한눈에 비교

| | 최적제어 | 예측 + 계획 | 게임 | Self-play RL |
|---|---|---|---|---|
| 상대 모델 | 없음 | 고정된 예측 | **합리적 최적화자** | 대결에서 암묵적으로 학습 |
| 계산 시점 | 온라인 | 온라인 | 온라인 (무거움) | **오프라인 학습**, 온라인 추론은 가벼움 |
| 출력 | 내 궤적 | 내 궤적 | 균형 궤적 쌍 | 정책망 $\pi_\theta$ |
| 보장 | 제약 | 제약 | 제약, 명확한 균형 개념 | 경험적 |
| 상호작용 | 없음 | 단방향 | **양방향** | 양방향 (암묵적) |

## 토이에서의 구현

모든 방법은 같은 **모션 프리미티브 10개** (2초 길이; 목표 횡위치 × 속도 모드) 중에서 고릅니다.
그래서 연속 문제가 **유한 행동 게임**이 됩니다. 계획 방법들은 10 × 10 조합을 모두 시뮬레이션해
효용 행렬을 만들고, 그 행렬을 어떻게 쓰느냐만 다릅니다.

| 방법 | 문제 정의 | 10 × 10 효용 행렬에 적용하는 규칙 |
|---|---|---|
| Solo MPC | 1 | 상대를 지운 채 내 진행거리 최대화 |
| Predict+MPC | 2 | "상대가 라인·속도 유지"에 대한 best response |
| Nash (IBR) | 3 | 반복 best response로 pure Nash 균형 (실패 시 maximin) |
| Stackelberg | 3 | 각 행동에 대한 상대의 best response를 고려해 내 효용 최대화 |
| Minimax (LP) | 3 | $\max_x \min_b x^\top U_{:,b}$ 를 LP로 풀고 $x$에서 샘플링 |
| Deep RL | 4 | 같은 10개 행동 위에서 self-play로 학습한 PPO 정책 |
